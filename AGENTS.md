# AGENTS.md

## Repository Context

- This repository is a Vite-powered client-side PWA for calculating lab media recipe volumes.
- Application code lives in `src/`.
- Recipe data lives in `data/recipes.json`.
- Build output is generated by Vite into `dist/`.

## Working Agreements

- Prefer `pnpm` for dependency and script commands.
- Keep the app static and client-side unless the task explicitly requires a different architecture.
- Avoid adding new dependencies unless they are necessary for the requested change.
- Preserve the existing single-file build approach used by the app.
- When changing recipe data shape or user-facing behavior, update `README.md` if the documented behavior is no longer accurate.

## Validation

- Run `pnpm build` after changes that affect app code, configuration, or recipe data.
- If a task cannot be validated locally, state that clearly in the final handoff.
